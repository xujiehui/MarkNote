# 备份与恢复

JSON 导出使用 `marknote-backup` V2 格式。导出前先完成当前空间的草稿保存，再在一个只读 IndexedDB 事务内读取笔记、文件夹、附件和历史，避免同步与导出之间出现不一致。保存失败时使用另一个应急恢复导出入口，分别保全已保存记录和未提交草稿。

包中保留空目录、回收站、时间、标签、置顶、目录顺序、附件字节与历史；偏好设置仅包括 `customTags`、`hiddenTags`、`tagColors`。同步队列、认证会话、账号凭据、云端文件路径和其他未知偏好字段不会导出。永久清除的数据不在包中。

未转成本地附件的外部媒体链接仍作为链接保留，恢复预检会提示其数量与离线限制；备份不会自动访问这些远端地址。未保存的临时 Blob 链接会阻断备份，避免产生无法重新打开的媒体。

每个附件有 SHA-256 字节校验，整个包另有 SHA-256 内容校验。正文使用稳定附件引用，避免把同一附件重复写入每个历史正文。校验可发现文件损坏，不能证明备份来源可信，也不提供加密。恢复前仍会检查字段类型、大小、重复标识、所属目录、附件所属笔记、引用与 MIME，并清洗正文。

一次导入最多 1000 个文件，总大小不超过 100 MB；单篇正文最多 20 MB，每个业务列表最多 100000 条，附件还受统一内容安全策略的 20 MB 上限限制。未下载的附件、缺失的引用或校验失败会阻断完整备份/恢复，不会悄悄丢弃内容后提示成功。

导入先显示笔记、目录、附件、历史数量与校验结果，不在预检界面执行或直接渲染导入 HTML。用户确认后可以选择：

- **创建独立副本**：为目录、笔记、附件和历史生成新的标识，并更新所有关联。原有笔记不会被覆盖。
- **跳过相同标识**：显式跳过目标空间中已有源标识的笔记，其余创建独立副本。每次复制导入都会生成新标识；再次导入同一包仍会产生新副本，这个选项不是内容去重。

恢复在一个事务中添加全部记录与待同步变更。任何写入失败或标识冲突都会回滚该文件的所有新增记录。导入期间空间切换也会中止事务；多个文件按文件顺序处理，前一个文件成功后，下一个失败不会撤销前一个文件。每个恢复的正文和历史会立即填充附件字节，因此离线情况下也能显示媒体。

V1 JSON、无版本的笔记数组，以及 Markdown/HTML 仍可导入。旧 JSON 缺少的目录名称会显示为恢复目录；独立附件、完整目录与历史不能凭空还原，预检会明确显示该限制。单篇 Markdown/HTML 导入使用当前选中的目录。

当前版本没有覆盖现有笔记的导入入口。需要替换内容时，应先导出当前空间，再检查导入副本并通过编辑器选择需要保留的内容。

无法完成正常保存或附件缺失时，可以使用单独的 **应急恢复导出**，文件名为 `marknote-recovery-日期.json`。它在只读事务中保全已保存记录、全部旧版/独立编辑器草稿及当前内存草稿；原笔记不存在或草稿时间相同都不会导致遗漏。可导入副本使用新的标识、安全内容和已有媒体字节，缺失媒体用明确说明替代。未经修改的原始业务正文、草稿与附件字节另外留在 `recovery` 数据段供后续修复，认证配置与远端文件路径不会导出。该文件不是完整 V2 备份，不自动消费草稿或修改数据库。

应急文件没有 V2 完整性校验，而且原始数据与独立副本会增加文件体积。直接导入仍受 100 MB 文件及 20 MB 单篇正文上限约束；超过上限的文件需要拆分或进行离线修复。

HTML/Markdown/PDF 导出会再次清洗内容。PDF 是图像式输出，文本不可搜索或选择。在禁止脚本执行的沙箱 iframe 中渲染，每页使用单独且有界的画布，最多 200 页，避免长笔记触发浏览器画布尺寸上限。分页按画布高度切片，复杂表格/图片跨页仍应在导出后检查。
